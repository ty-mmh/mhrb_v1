# まほろば 利用ガイド

この配布版を使い始めるための入口です。実行方法を選び、管理画面でResidentを作成して対話を開始します。

| 目的 | 読む資料 |
| --- | --- |
| ローカルでビルドして使う | [導入と最初の対話](guide/getting-started.md) |
| Docker Desktopで使う | [Dockerで使う](guide/docker.md) |
| 起動・停止、Resident管理、会話の操作 | [日常操作](guide/operations.md) |
| 生成サービス、保存先、self-talk、Tailscaleの設定 | [設定](guide/configuration.md) |
| Bootstrap、起動、接続のエラー | [トラブル解決](guide/troubleshooting.md) |
| 管理画面の全操作とHTTP仕様 | [Web administration](guide/web-administration.md) |
| ソースとテストを検証する | [ソースの検証](testing.md) |

設定項目は[設定ファイルの例](../config.example.toml)を参照してください。

配布対象の範囲は[配布内容の説明](../DISTRIBUTION.md)に記載しています。過去の計画・監査アーカイブは同梱していません。固定資料は[テスト用の基準資料](../testdata/docs-baseline/README.md)として分離し、現在の操作ガイドとは区別しています。
