Creating your first resident
  1. Review the owner, name, and principles in Bootstrap init, run it, and keep the resident ID shown in its result.
  2. Run Bootstrap approve for that resident as a separate decision to approve those principles.
  3. Run Bootstrap finalize to activate the resident.
  4. Use Start dialogue server below, wait for it to be running, then open dialogue.

This management server uses the configuration and data directory chosen when it was started. Operations marked “Stop dialogue first” need exclusive access. Stop the dialogue server and wait for shutdown to complete before running them.
